# Agents Skills Directory

This directory contains skill definitions for the AI agent.

## Available Skills

- `jev-agent`: Use the Jev AI decision API for typed choices, scores, or yes/no judgments
- `ponytail`: Lazy senior dev mode for coding tasks - YAGNI, stdlib first, no unrequested abstractions. Reduces code by ~54%, costs by ~20%, time by ~27%, 100% safe.
- `typesafe-ai`: Build AI-powered software with TypeSafe - small units of AI intelligence as programming primitives. System One models (Jev) return typed judgments (boolean, choice, score, extract) for routing, verification, ranking, extraction.

## Adding Skills

To add a new skill:

1. Create a directory under `.agents/skills/` for the skill name
2. Add a `SKILL.md` file with the skill description and usage instructions
3. Reference the skill in your agent configuration

## Example Structure

```
.agents/
├── skills/
│   ├── jev-agent/
│   │   └── SKILL.md
│   ├── ponytail/
│   │   └── SKILL.md
│   ├── typesafe-ai/
│   │   └── SKILL.md
│   └── your-skill-name/
│       └── SKILL.md
└── README.md
```
